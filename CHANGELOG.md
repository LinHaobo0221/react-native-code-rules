## 0.1.0

- Established the shared React Native / Expo rules entry point and required reading order.
- Defined the standard `mobile/` directory structure, responsibility boundaries, and routing principles.
- Defined component, styling, Figma, cross-platform interaction, accessibility, and delivery rules.
- Defined performance rules for React rendering, virtualized lists, images, asynchronous work, and profiling.
- Defined unit, Hook, component, integration, race-condition, and native testing strategy.
- Defined data classification, protected storage, token Auth, networking, permissions, and privacy rules.
- Added project-specific `app-specific.md` templates.
- Added complete Simplified Chinese (`zh-CN`), Japanese (`ja`), and English (`en`) rulesets and project templates.
- Added explicit `rules_language` selection with English fallback instead of language inference from device locale or code.
- Adopted the MIT License under `LinHaobo0221`.
- Kept the package documentation-only, with no UI, Tokens, motion, or business implementation.
