# 11. プロジェクト固有の `app-specific.md` に必ず記載する内容

各プロジェクトで、`mobile/docs/agents/app-specific.md` または同等のプロジェクト固有文書を別途管理する。未確定の内容は「未確定」と記載し、別のアプリの設定で代用してはならない。

1. **プロジェクトの基本情報**：規約の言語、アプリ名、`mobile/` のパス、パッケージ名、Expo SDK、React Native、React、パッケージマネージャー、ネイティブの開発ワークフロー。
2. **必読文書**：アーキテクチャ、API の契約、データとストレージ、キーボード表示時のレイアウト、テスト規約、リリース規約。
3. **ディレクトリとパスエイリアス**：標準構成を採用するかどうか、承認済みの追加ディレクトリ、`model` / `use-cases` の使用条件、エイリアス、`index.tsx` とページのエクスポートに関する規約。
4. **ルーティングとナビゲーション**：ルートグループ、Root Stack、Tabs、Tab Stack、タブをまたぐページ、Modal、ルート定数、アニメーションと戻る操作の要件。
5. **デザイントークン**：コード上で正とする定義、Figma Variables / Library、色、余白、角丸、影、タイポグラフィ、z-index、テーマモード。
6. **フォントと言語**：対応言語、フォント、フォールバック、フォントウェイトの対応関係、動的な文字サイズ、最大拡大率。
7. **モーション**：モーショントークン、ナビゲーション、Modal / Sheet、押下フィードバック、読み込み中の表示、視差効果や動きを減らす設定への対応、禁止する実装。
8. **スタイリングと基本コンポーネント**：スタイリングの仕組み、スタイルを同じファイルに置くか分離するかのルール、テーマ、Button、Input、Switch、Checkbox、Radio、Image、Avatar、Modal、Sheet、キーボード対応、読み込み中・データなし・エラー表示のエントリーポイント。
9. **共通コンポーネント一覧**：公開するプリミティブとパターン、エントリーポイント、直接の利用側、バリアント、非推奨のコンポーネント、使用例の場所、スタイルの外部変更を許容する範囲。
10. **画像、SVG、アイコン**：アセットのディレクトリ、SVG の組み込み方法、アイコンの入手元、複数倍率のビットマップ、プレースホルダー、フォールバック、命名規則。
11. **データ、API、状態**：API クライアント、レスポンスの外側の構造、Controller・Use Case・Reducer・Strategy・Adapter・Repository の使用条件、認証、トークン、KV、オフラインデータ、ファイルキャッシュ、スコープ付きイベントと状態、禁止する仕組み。
12. **制御フローの規約**：主要な操作の経路、Controller の戻り値の構造、Use Case の結果に関する規約、エラーマッピング、ナビゲーションの管理責任、送信ロック、キャンセル、古い結果の扱い。
13. **再利用方針**：再利用候補の検索範囲、Feature First、shared に移す条件、移行と元の層に戻す手順、許可するスロットとバリアント、残った重複コードに追加対応する条件。
14. **プラットフォーム設定**：iOS / Android の最低対応バージョン、エッジツーエッジ表示、StatusBar、システムナビゲーション、セーフエリア、権限、プラットフォーム間の差異。
15. **性能とレンダリング**：対象デバイス、性能上重要な処理経路、リリースビルドでのプロファイリング、ツール、性能上の許容上限、リストの規模、仮想化リスト、画像キャッシュ、キャッシュの管理責任、クリーンアップ方針。
16. **テスト戦略**：テストランナー、各層で使用するツール、Use Case/Reducer/Controller のテスト、ネイティブ機能のモック、セットアップとクリーンアップ、対象範囲（include）、テスト ID、カバレッジ、不安定なテストへの対応、両プラットフォームの受け入れ確認マトリクス、CI のチェック。
17. **セキュリティとプライバシー**：データ分類、認証の契約、保護されたストレージ、KV・データベース・キャッシュ、API のオリジン、HTTP を許可する例外、ディープリンク、WebView、権限、ログのマスキング、SDK の同意取得、ログアウトと削除時のクリーンアップ。
18. **依存パッケージの制約**：許可する UI・アニメーション・ジェスチャー・ネイティブモジュール、新しい依存パッケージの承認、ワークスペースの依存関係と Expo config plugin に関するルール。
19. **Figma ワークフロー**：チームとプロジェクト、デザインライブラリ、ページのファイル、Dev Mode / Code Connect、アセットのエクスポート権限、トークンと共通コンポーネントの整合を取る手順、見た目の受け入れ確認に使用するデバイス。
20. **検証と引き渡しのためのコマンド**：format、lint、typecheck、test、依存関係の境界チェック、iOS、Android、引き渡し前の必須チェック、CI のチェック、既存の問題の記録場所。
21. **プロジェクト固有の禁止事項**。
22. **承認済みの例外**：対象の共通ルール、例外とする理由、影響範囲、代替措置、受け入れ確認の方法、有効期限または見直しの条件。
